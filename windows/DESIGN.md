# Windows 版のデザイン方針

無機質な金属をテーマにした、フラットな配色です。ダークはガンメタル、ライトは
明るいスチールグレーで、どちらも青みのある灰色の単色の面です。グラデーション・
光沢・影は使わず、1px の境界線と半径 4px の角で区切ります。アクセントも青ではなく、
スチールブルーグレーにします。縦タブと専用の新しいタブ画面で独自の外観を作ります。

## 今回反映した要素

- 配置は以前の Still（Tauri 版、`site/public/img/hero-*.png`）に合わせる。新規プロファイルでは縦タブを最初から表示。初期幅は 200px。
- サイドバー上部に「タブ・ブックマーク・履歴・ダウンロード」のセグメント、「タブ」の見出し。タブはタイトルとホスト名の2行で、サイトのファビコンを常に表示。読み込みや音声の表示は Firefox の標準動作を使う。設定ボタンはタブ欄の一番下に固定し、折りたたみ時も歯車アイコンを表示。Firefox の下部のツールボタンはこのセグメントで置き換えて隠す。
- 新規プロファイルはライト（スチール）。キャンバス `#e3e6e9`、面 `#f3f5f6`、文字 `#1c2024`、主操作とリンク `#3e5366`。ダーク（ガンメタル）はキャンバス `#24282c`、面 `#2e3337`、文字 `#e6e9ec`、主操作 `#4a5d6e`、リンクとフォーカス `#9fb2c3`。文字は 4.5:1、操作部品の境界線は 3:1 以上のコントラスト。
- 高さ 40px のツールバーと、枠線のない塗りのアドレス欄（編集中以外は中央揃え）。サイドバー切り替えボタンは塗りの角丸。
- ページは半径 4px の角と 1px の境界線。右と下に 4px の余白。ボタンもピル型ではなく半径 4px。
- 選択中のタブとセグメントは、影ではなく面の色と 1px の線で区別し、キーボードフォーカスには 2px の輪郭を表示。
- 幅の狭いウィンドウではサイドバーの最大幅を抑える。
- 動きを減らす設定、透明効果を減らす設定、高コントラスト表示への対応。
- 設定画面はアイコン付きの項目メニューと検索欄で移動。検索は見出し・説明・別名で項目を絞り込み、Esc やメニュー選択で元に戻ります。検索語は設定に保存しません。
- 設定項目はアクセントの線でも区別。設定のスイッチはラベル全体から操作できます。
- 新しいタブはローカルの `chrome://still/content/newtab.html`。既定の検索エンジンで検索し、ブックマーク・履歴・ダウンロードへ移動できます。外部の画像やフォントは読み込みません。
- 新しいタブの背景画像は従来のランチャー経由で設定。写真に淡い面を重ね、文字の視認性を保ちます。
- 新しいタブは中央に見出しと検索欄、下にライブラリーのリンク。設定はカードを重ねず、余白と罫線で階層を表現。SF Pro がなければ各 OS の UI フォントにフォールバックします。

## 実装の境界

Firefox のタブ制御・アドレス補完・サイト識別情報・権限表示を使います。
Firefox への変更は、メモリ使用量を減らす既定値とアロケーターの調整（`gecko/patches/`）に限ります。
画面の変更は、これまでどおり AutoConfig と CSS で行います。
Zen 独自のワークスペース、Glance、分割表示、フローティングアドレスバー、
Compact Mode は今回の実装範囲には含みません。

色は `firefox/still/content/tokens.css` に集約します。設定画面は直接読み込み、
ブラウザのフレームは Rust ランチャーが `userChrome.css` に埋め込みます。
Linux 共通 CSS → Windows 色定義 → Windows レイアウトの順で適用します。
セグメントとタブのホスト名は AutoConfig（`firefox/still.cfg`）がウィンドウごとに追加します。
組み込みページには Windows 色定義と `profile/userContent.css` を適用します。
通常のウェブサイトには適用しません。AutoConfig は起動時に新しいタブの URL を登録します。

Firefox 153 ではサイドバーのコンテナーが `#sidebar-container` に変わったため、
旧版の `#sidebar-main` と両方に対応します。153 の幅は Firefox が保存する
インライン指定を優先し、利用者のドラッグ調整を維持します。

## 既存設定の扱いと確認

縦タブの初期表示は新規プロファイルにだけ設定します。移行リビジョンを上げず、
既存のテーマ、サイドバーの開閉・幅、ホームページ、ツールバーのカスタマイズは引き継ぎます。
専用ホームページの初期値は新規プロファイルにだけ設定します。

`cargo test --offline --locked --manifest-path windows/launcher/Cargo.toml` と
Windows の Python・Node テストで、プロファイル生成・設定操作・配布ファイルを
確認します。Windows 実機での表示、ウィンドウ操作、高コントラスト表示は
別途確認が必要です。
